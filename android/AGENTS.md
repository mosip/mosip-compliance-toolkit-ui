# AGENTS.md — `android/`

> Capacitor-generated native Android project packaging the Angular codebase for on-device
> SBI (biometric device) testing. Parent guide: [repo root `AGENTS.md`](../AGENTS.md).

---

## 1. Purpose

`src/` is compiled with `ng build -c=android` (using `environment.android.ts`) and wrapped by
Capacitor into a native app that calls biometric devices via `mosip-sbi-capacitor-plugin` instead
of the browser-only SBI flow. Tracked in git (not a build artifact), kept in sync with
`capacitor.config.ts` (repo root) via `npx cap sync`.

## 2. Layout

```text
android/
├── build.gradle              # top-level Gradle build (AGP 7.2.1, google-services 4.3.13)
├── variables.gradle          # shared SDK/library versions (compileSdk 32, minSdk 22, targetSdk 32, ...)
├── settings.gradle, gradle.properties, capacitor.settings.gradle
├── gradlew, gradlew.bat, gradle/            # Gradle wrapper
└── app/
    ├── build.gradle           # applicationId io.mosip.compliance.toolkit, versionCode/versionName
    ├── capacitor.build.gradle # Capacitor plugin wiring (regenerated by `npx cap sync`)
    ├── proguard-rules.pro
    └── src/                   # native sources/resources + synced web build output
```

`applicationId io.mosip.compliance.toolkit` (`android/app/build.gradle`) — keep in sync with any
Keycloak client / deep-link config on the backend.

## 3. How to run

Mirrors `.github/workflows/android.yml`; run from the **repo root**:

```shell
npm install --ignore-scripts

# CI defaults below point at MOSIP's shared dev env — override for your own target.
export NX_APP_SERVICES_BASE_URL="<services-base-url>"   # CI default: https://api-internal.dev.mosip.net/v1/toolkit/
export NX_APP_IAM_URL="<iam-url>"                        # CI default: https://iam.dev.mosip.net/auth
export NX_APP_IAM_REALM="<iam-realm>"                    # CI default: mosip
export NX_APP_IAM_CLIENT_ID="<android-client-id>"        # CI default: mosip-toolkit-android-client

ng build -c=android
npx cap sync
cd android
chmod +x ./gradlew
./gradlew build
# debug APK: android/app/build/outputs/apk/debug/app-debug.apk
```

CI runs this same sequence on `develop` pushes or manual `workflow_dispatch` (prompts for
`services_base_url`/`iam_url`), using Angular CLI `13.0.0` — intentionally lower than the web
build's `~13.3.2` (root `AGENTS.md`); don't "fix" the split without checking both pipelines.

## 4. Agent rules — Do / Do not

### Do

- Run `npx cap sync` after any `capacitor.config.ts`, `@capacitor/*`, or
  `mosip-sbi-capacitor-plugin` change, so `capacitor.build.gradle` stays current.
- Keep shared version numbers in `variables.gradle`, not hardcoded in `app/build.gradle`.
- Call out Android-affecting PRs explicitly (root `AGENTS.md`) — Android CI only runs on `develop`
  push or manual dispatch.

### Do not

- Don't hand-edit `app/capacitor.build.gradle` — regenerated by `npx cap sync`; edit
  `capacitor.config.ts`/plugin deps and re-sync instead.
- Don't commit `google-services.json` with real Firebase credentials — its absence is tolerated
  (push notifications just won't work).
- Don't delete `android/` as if disposable — it's tracked; regenerate sub-files via `cap sync`.
